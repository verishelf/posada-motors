# Posada Motors

**Precision. Presence. Power.**

Official website for **Posada Motors** — V8 hybrid supercars.

## Theme

**Black & White · Lamborghini-inspired**

- Pure black backgrounds, pure white text & accents
- High-contrast, aggressive geometry
- Sharp edges, angular details, bold uppercase tracking
- Dramatic film-grain noise and radial lighting
- No color — only monochrome intensity

## Brand Focus

Limited-series **V8 hybrid supercars**: twin-turbo V8 soul + electric torque.

### Models
- **Apex** — Grand Touring Hybrid (1,250 hp)
- **Pulse** — Track hybrid (1,480 hp)
- **Horizon** — Open-air roadster (1,180 hp)

## Tech Stack

- Next.js 16 · React 19 · TypeScript
- Tailwind CSS v4
- Framer Motion · Lucide React

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
