# Posada Motors

**Precision. Presence. Power.**

Official website for **Posada Motors** — V8 hybrid supercars.

## Theme

**Black & White · Rounded cards & chips**

- Pure black backgrounds, pure white accents
- Soft rounded cards (`rounded-3xl`) and pill chips
- Floating glass navbar with rounded container
- Chip-style stats, tags, and section labels
- Soft hover lifts and glow on interactive elements

## Brand Focus

Limited-series **V8 hybrid supercars**: twin-turbo V8 soul + electric torque.

### Models
- **Apex** — Grand Touring Hybrid (1,250 hp)
- **Pulse** — Track hybrid (1,480 hp)
- **Horizon** — Open-air roadster (1,180 hp)

## Tech Stack

- Next.js 16 · React 19 · TypeScript
- Tailwind CSS v4
- Framer Motion · Lucide React

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
