# Posada Motors

**Precision. Presence. Power.**

Official website for Posada Motors — a next-generation luxury electric vehicle company.

## Design Philosophy

Built to surpass the minimalist restraint of Tesla’s digital presence:

- **Cinematic dark theme** with electric teal accent and subtle violet undertones
- **Glassmorphism** navigation and cards with refined blur and borders
- **Premium typography** pairing Playfair Display (headlines) with Geist Sans
- **Micro-interactions** and scroll-triggered motion via Framer Motion
- **Ambient lighting**, gradient orbs, and noise texture for depth without clutter
- **Full-bleed sections** with strong hierarchy and breathing room
- **Responsive** from mobile to ultra-wide

## Tech Stack

- **Next.js 16** (App Router)
- **React 19**
- **TypeScript**
- **Tailwind CSS v4**
- **Framer Motion**
- **Lucide React** icons

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
