# Posada Motors

**Precision. Presence. Power.**

Official website for **Posada Motors** — a next-generation V8 hybrid supercar company.

## Brand Focus

Posada builds limited-series **V8 hybrid supercars** that combine the emotional soundtrack and character of a twin-turbo V8 with the instantaneous torque and efficiency of high-output electric motors.

### Models
- **Apex** — Grand Touring Hybrid (1,250 hp combined)
- **Pulse** — Track-focused hybrid supercar (1,480 hp)
- **Horizon** — Open-air hybrid roadster (1,180 hp)

## Design Philosophy

Built to feel more sophisticated and cinematic than typical minimalist automotive sites:

- Cinematic dark theme with electric teal accent
- Glassmorphism navigation and cards
- Premium typography (Playfair Display + Geist)
- Framer Motion micro-interactions and scroll reveals
- Ambient lighting, gradient orbs, and subtle noise texture
- Full-bleed sections with strong hierarchy

## Tech Stack

- Next.js 16 (App Router)
- React 19 + TypeScript
- Tailwind CSS v4
- Framer Motion
- Lucide React

## Getting Started

```bash
npm install
npm run dev
```
